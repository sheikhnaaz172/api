#Order Placement Springboot Application.
This Java Application allows customers to place orders. It Utilizes REST API and Maven build tool.
Technologies used:
  Java 8,
  REST API,
  Maven,
  PostgreSQL,
  ORM Tool- Hibernate,
  JPA,
  Swagger API Documentation.
